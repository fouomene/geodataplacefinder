Project Name: GeoDataPlacefinder
Objective:
Build an open-source geocoding API that converts addresses into geographic coordinates (latitude/longitude) and performs reverse geocoding, using Overture Maps data queried through DuckDB, without relying on traditional turnkey services like Google Maps or Nominatim.

📌 Context
Overture Maps provides rich geospatial datasets but does not offer a ready-to-use geocoding service.
This project bridges that gap by creating a backend API capable of querying Overture Places data to resolve locations from text-based queries.

🚀 Solution Overview
GeoDataPlacefinder is an open-source backend API that enables:

Geocoding: Convert place names or addresses into coordinates
Reverse Geocoding: Convert coordinates into human-readable addresses

The API is:

Available on GitHub
Documented via a dedicated website (similar to Nominatim)
Designed to be scalable, fast, and production-ready
also Dockerfile


⚙️ Core Features
1. Geocoding (Search by text)

Supports free-form queries (e.g., "Cafe Paris, New York")
Supports structured queries:

postcode=12345
city=London
type=cafe


Multi-language support
Suitable for bulk address processing

2. Reverse Geocoding

Input: latitude & longitude
Output: nearest address or place


🧱 Technology Stack

FastAPI → REST API layer
DuckDB → High-performance SQL engine
Overture Maps → Source of POI data (remote Parquet files)
Data Access → Direct HTTPS queries (no local storage required)


🔄 Data Flow
Input:
➡️ Name and/or address
Processing:
➡️ DuckDB queries Overture Places dataset
Output:
➡️ Structured POI data:

Latitude / Longitude
Place name
Categories
Source metadata
Confidence score

## ⚙️ Architecture

Client → FastAPI → DuckDB → Overture Maps → JSON response

## 📡 Example API Usage

### Geocoding
GET /search?q=Cafe Paris New York

### Reverse
GET /reverse?lat=48.8566&lon=2.3522

/health - query the status of the server

⚡ Production Best Practices

✅ Use DuckDB as a singleton (avoid reinitializing per request)
✅ Add caching layer (e.g., Redis) for frequent queries
✅ Optimize queries for large-scale datasets


💡 Summary
GeoDataPlacefinder is a lightweight, open-source geocoding engine powered by Overture Maps and DuckDB, designed to provide flexible, scalable, and cost-effective geolocation services without relying on proprietary APIs.
