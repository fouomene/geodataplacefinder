API Documentation
Complete reference for the GeoDataPlacefinder REST endpoints.

Base URL
https://geodataplacefinder.org
Endpoints
GET
/api/health
Returns the current server status, API version, uptime, and the number of places loaded in the local cache. Useful for readiness checks and monitoring. Also available at /api/healthz for backwards compatibility.

Response fields
status
Always "ok" when the server is running
version
API version string
uptime_s
Seconds elapsed since the server started
cache_rows
Number of place records loaded in the local DuckDB cache (0 if still warming up)

curl "https://geodataplacefinder.org/api/health"
GET
/api/search
Free-form or structured text search against Overture Maps Places data. Converts place names or addresses into geographic coordinates.

Free-form query
q
Free-form search string. Can include any combination of name, address, city, or category (e.g. "Cafe Paris New York", "123 Main St London").
Structured query
Use individual fields for precision. Filters are combined with AND.

name
Place or business name (e.g. "Eiffel Tower")
city
City or locality (e.g. "London")
postcode
Postal or ZIP code (e.g. "75001", "SW1A 1AA")
type
Place category (e.g. "cafe", "restaurant", "hotel")
limit
Maximum number of results (1–20). Default: 5

curl "https://geodataplacefinder.org/api/search?q=Hilton+Hotel&limit=5"
GET
/api/reverse
Converts geographic coordinates (latitude/longitude) into the nearest human-readable place name and address.

Query Parameters
lat *
Latitude (WGS84)
lon *
Longitude (WGS84)

curl "https://geodataplacefinder.org/api/reverse?lat=39.7460&lon=-75.5480&limit=5"
GET
/api/places/nearest
Returns the single closest place to a given coordinate within a configurable radius. Optionally filter by name to find the nearest matching business or landmark.

Query Parameters
lat *
Latitude (WGS84)
lon *
Longitude (WGS84)
max_distance_m
Search radius in metres. Default: 5000
name
Optional name filter — only return places whose name contains this string

curl "https://geodataplacefinder.org/api/places/nearest?lat=39.7460&lon=-75.5480&max_distance_m=5000"
GET
/api/places/:id
Returns all available Overture Maps data for a single place looked up by its ID. Every search, reverse, and nearest result includes an id field — pass it here to retrieve the full detail record.

Path Parameter
id *
Overture place identifier in the format overture:place:<uuid>
Response fields
id
Overture place identifier
names
Full names object — primary name, common aliases, rules
addresses
Structured address list — freeform, locality, postcode, region, country
location
Coordinates object { lat, lon }
confidence
Data confidence score (0–1)
categories
Primary and alternate category tags
sources
Data provenance records — dataset, license, record_id, update_time
websites
List of website URLs
phones
List of phone numbers
socials
List of social media profile URLs
emails
List of email addresses
brand
Brand information — name, Wikidata identifier

curl "https://geodataplacefinder.org/api/places/overture:place:ac0aed88-e6cb-4224-9520-441339447760"
